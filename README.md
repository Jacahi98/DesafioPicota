# Desafío Picota

Web oficial de Desafío Picota, una carrera de trail running costero en Liencres
(Cantabria), dentro del Parque Natural de las Dunas, con final en el mirador de
Monte Picota y la ría de Mogro abriéndose debajo. Próxima edición: 24 de abril
de 2027.

## Qué tiene la web

- Recorrido interactivo con mapa, perfil de elevación animado y estadísticas
  de distancia/desnivel en vivo, para las modalidades Trekking y Andarines.
- Inscripción online con formulario propio y pago por transferencia con
  verificación manual.
- Panel de administración protegido para gestionar inscripciones.
- Página de recorrido alternativo y política de privacidad.

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion · Postgres (Neon) +
Drizzle ORM · Resend (emails) · Zod

## Desarrollo local

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
